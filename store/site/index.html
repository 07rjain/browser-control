Codex beside the page

Supervised browser work from Chrome's side panel.

Browser Control combines Codex chat with explicit page attachment, tab organization, and a fixed set of visible, user-initiated browser actions.

Install the companion Read the privacy policy

What it does

Side-panel chat

Sign in through Codex with an eligible ChatGPT account, choose an available model, and keep local conversation history beside your tabs.

Explicit context

Attach the current page only when you choose. Review its origin and size before its selected or readable text is sent.

Visible actions

Use typed, allowlisted tab and page actions with activity history, Stop, permission controls, short-lived element references, and hard safety refusals.

You choose the access level

Ask every time grants exact-site access as needed and confirms supported consequential actions. Full access requests optional access to normal HTTP and HTTPS pages once and can perform supported submit, save, send, publish, delete, schedule, and tab-close actions after your request without a separate extension confirmation card. Both modes show activity, enforce action limits, support cancellation, and refuse purchases, credentials, payment data, authentication codes, private keys, CAPTCHAs, and security bypasses.

macOS companion required. Browser Control communicates with the locally installed Codex CLI through Chrome Native Messaging. It currently requires macOS, Node.js 20 or newer, Codex CLI, Google Chrome or Brave, and an eligible ChatGPT/Codex account. See the installation guide.

Current limitations

Protected Chrome pages, cross-origin frames, browser dialogs, closed shadow roots, and canvas-only controls are unsupported. Page inspection returns at most 80 visible interactive controls, so a control on a dense page may not be available. Browser Control is not remote or unattended automation.

Browser Control is an independent extension and is not affiliated with or endorsed by OpenAI.
